**一句话**：模型只负责"**把手带到果子能落进指间的那个位姿**"，其余（抓、抬、放、松）由确定性原语执行；原语的每一步都量过，且每一处"等待"都证明过它是不是"起步信用"。

## 1. 单元（俯视）

```
                     皮带 −y 方向（0.08 m/s 起，实测可用到 0.18）
   ┌───────────────────────────────────────────────────────────────────┐
   │  ▓▓▓ 散料池（16 颗，A:B:C = 0.375:0.375:0.25，沿带 0.10–0.35 m 间隔）│
   │      x ∈ [0.20, 0.36]（实测可放宽到 0.17–0.39 不掉率）              │
   └───────────────────────────────┬───────────────────────────────────┘
                                   │  果子随带进入"选择窗"
                          ┌────────▼────────┐
                          │  取料站（单臂）   │  ← Franka Panda
                          │  顶抓（T0 姿态）  │     指垫 76 mm 宽
                          └────────┬────────┘
                                   │
                    ┌──────────────┴──────────────┐
                    ▼                             ▼
           料箱 0（左臂侧，+Y）           料箱 1（右臂侧，−Y）
           箱底 1.10 m，浅沿口 1.13 m     同规格；盒内释放底面 ≈ 箱底 +39 mm
```

**三条硬约束**（都是量出来的，不是设计选择）：

1. **臂受限，不是线受限**：0.08 与 0.12 的尝试时长都是 **11.8–11.9 s**、返回都是 2.25–2.74 s → 提高带速**不增件/分**，只增失败（P257）。
2. **可用带速上限由接触段决定**：0.18 → 11/12，0.20 → 7/12，0.24 → 0/6；接合天花板 `0.2055 m/s` 只是"选择器能否看见果子"（P229）。
3. **释放底面在箱底之上 39 mm**（P227ac 实测 39–40），箱沿 3 cm（P227ac 加注）——所以指尖在放料段不进入沿口以下。

## 2. 四层时间栈（谁在什么频率上做决定）

```
┌─ L1 Track ──── 30 Hz ────────────────────────────────────────────────┐
│ 相机 → 掩码 + 深度 → 裁剪球拟合 → 卡尔曼（CV，自适应过程噪声）        │
│ 实测：能看见时位置 p50 1.9–9.5 mm；速度 0.124–0.135 vs 带 0.120      │
│ 限制：手会遮住果子（1/6 帧可用），所以估计器靠"预测穿越遮挡"          │
└──────────────────────────────────────────────────────────────────────┘
┌─ L2 Time ───── 10 Hz ────────────────────────────────────────────────┐
│ 到达时刻预测 → `lead`（时间预算）→ 选择窗地板 → 触发时刻             │
│ 实测：回路内决策延迟 66 ms = 8 mm（0.12 下）；单元吸收 ≤133 ms        │
└──────────────────────────────────────────────────────────────────────┘
┌─ L3 Task ───── 2–5 Hz ───────────────────────────────────────────────┐
│ 选哪颗（分轴地板 / 里程偏好 / 命中规则指令）→ 派给哪条臂 → 账本       │
│ 实测：0.12 的真停滞 = 选择后的**自由空间追赶**（10 次里 8 次无接触）  │
└──────────────────────────────────────────────────────────────────────┘
┌─ L4 Approach ─ 30 Hz 决策 / 120 Hz–1 kHz 执行 ───────────────────────┐
│ 扩散策略出 8 维动作 → 4 tick/waypoint（=示教 30 Hz）→ 5.45 rad/s 限速 │
│ 实测：模型占一次取放的 9–12% tick；延迟必须用**回路内**的数：66 ms    │
│ = 8 mm（0.12 下）；离线台的 26.4 ms（DDIM-16）**不能当回路延迟引用**  │
└──────────────────────────────────────────────────────────────────────┘
┌─ L5 Touch ──── 200–1000 Hz（控制内环 120 Hz）────────────────────────┐
│ 追够 → 闭合 → 破带 → 静止 → 抬升 → 转位 → 伴降 → 释放 → 返回         │
│ 每段都有实测时长与守卫；每处 settle 都验证过是否"起步信用"            │
└──────────────────────────────────────────────────────────────────────┘
```

## 3. 一次取放的时序（实测块时长，0.08 m/s，和 9.47 s 对总 9.49 s）

```
 t=0    ┌ descent  1.06 s  等果 + 下降（含 `lead/speed − margin` 的等待，不可缩短）
        ├ seat     0.17 s  追够（分轴退出：|y|≤6、|z|≤10 → 21–42 tick）
        ├ close    1.10 s  闭合（**不要缩短**：更慢的闭合转化握持类）
        ├ lift_takeoff 0.78 s  破带起飞斜坡（抗剪切）
        ├ lift_settle  0.47 s  静止等待（2 mm/s→10 mm/s 后由 0.79 降来）
        ├ lift     1.21 s  抬升腿（两臂对齐后一致）
        ├ place_clear 0.78 s  上抬 0.10 m 清空（其中 0.43 s 是**梨的保护**）
        ├ place_blend 1.08 s  关节混合到 `bin_above`（90 tick + 40 tick settle）
        ├ place    1.14 s  Cartesian 转位（剖面自身的平均速度）
        ├ rel_low  1.23 s  伴随下放到箱底 +39 mm
        ├ rel_pads 0.33 s  垫斜坡 40 步 × 1 tick
        ├ rel_fing 0.13 s  手指斜坡 16 步 × 1 tick
        └ return   0.00 s  已与返回航段的 `_lift_clear` 合并（去重）
 t≈9.5  └ 判 placed（释放后 0.5 s 采样）

 集间：返回航段 263 tick（2.2 s）→ `gap` 实测 **双峰**：270 tick 或约 460 tick
       （"臂在等果" vs "臂立刻有活"，值 0.7 件/分）
```

**时间去哪了**：`descent` 的等待（不可动）· `close`（不要动）· 三处 settle（要动就成对量）· 两处剖面（已在自身地板）。

## 4. 模型卡（唯一的可学习组件）

| 项 | 值 |
|---|---|
| 文件 | `checkpoints/p227_panda156/policy_best.pt`，md5 **`6ec25f54`**（前 12 位） |
| 结构 | 扩散策略（DDIM-16），**4.59 M 参数**，**5 专家 MoE**（`_mix_experts` 在权重≈0 时跳过专家，所以 5 专家并不比 1 专家慢）；`--num-skills 1` 的形式是 **3.80 M（−17 %）**，在 n=12 上与 5 专家**打平**（11/12 对 12/12），但默认仍是 5 专家 |
| 输入 · 视觉 | **2 帧** RGB 240×424（缩放到策略输入分辨率），头部相机；**这就是模型看到的世界** |
| 输入 · 本体 | **12 维**：9 关节 + 1 指 + 2 触觉（双侧合力）；可选第 13 维为带速 |
| 输入 · 目标 | **8 维**：位置 3 + 速度 3 + 直径 1 + 箱号 1（`FRUIT_OBS_GOAL_AUX=1` 时加带速/带加速度 → 10 维） |
| 输出 | **8 维动作**：7 关节绝对目标 + 1 指目标 |
| 执行 | 4 tick/waypoint（=示教 30 Hz）· `execute_steps=4` · 目标限速 **5.45 rad/s** · 关节夹紧到 `get_dof_limits()` |
| 训练 | 从零训练于 `datasets/p227_panda_all`（**156 集 / 25 775 帧 / 23 123 窗口**），12 epoch，val **0.0276**，router 0.990 |
| 训练数据来源 | 脚本原语自己的成功轨迹（两线采集器 + 单臂采集器），**成功率过滤** |
| 已知限制 | ① 没有"追着走"的能力（`gap_close` 中位 150 mm，需要外部到达触发）；② 小果/梨的握持落在硬件类；③ 图像只是"外观通道"，目标向量才是真值（`goal` 来自感知时 10/12 可用，接触期只有 15–18% 帧可用） |

**为什么这么分工**：记录里量到"模型自己闭合"从不发生（0/7），而"模型 + 到达触发"把单元做到 **99.3%**——所以**模型是接近控制器，不是抓取控制器**，这是实测结论，不是偏好。

## 5. 学习 / 脚本 的分界（图上最容易被问的一点）

```
            学习（模型）                    脚本（确定性原语）
   ┌──────────────────────────┐   ┌──────────────────────────────────┐
   │ 接近：从等待位姿到抓取位姿 │   │ 追够：目标 = 果子 + (0,0,standoff) │
   │ 时机：由 `arrival` 触发外   │   │ 闭合：力伺服 + 冻结 + 破带       │
   │       部规则接管           │   │ 抬升/转位/伴降/释放 → 账本        │
   └──────────────────────────┘   └──────────────────────────────────┘
        可换（换检查点即换）              不可换（换即换场景）
```

- **触发有两种**：`FRUIT_POLICY_TRIGGER=arrival`（外部规则，出厂配方）或 `off`（模型自己闭合 —— 实测 0/7，不可用）。
- **接触后全是脚本**：所以"换模型"不影响抓取质量；"换垫面/箱/工位"才影响。
- **指令层**（`FRUIT_SORT_INSTRUCTION`）：`grade=A => 0`、`size<40 => 1`、`species=apple and size>=66 => 2`、`default`、`skip`；能力图拒绝不可达的目标；账本按**释放实测位置**判 `in_destination`（料箱按 settle 采样）。

## 6. 测量骨架（"不作弊"在这里）

```
             ┌──────── 每个旋钮默认关闭 ────────┐
             │ 未设 = 逐位等于出厂（可复算证明）  │
             └───────────────┬────────────────┘
                             ▼
   预注册（PREREG.md 先钉）→ 单元格（≥2 种子，含新鲜种子）→ 端点判据 → 判决
                             │                              │
                             ▼                              ▼
             分支不可归因：跨臂计数只在同分支可比      "读数不是速率"：
             一个 tick 变化即重抽供给                 诊断格/延迟格/6 集格都不给速率
```

**四条读法（都是被自己的数据打出来才写下的）**：

1. **分支不可归因**：两臂序列一旦分叉，计数差就不是杠杆的。
2. **绝对杠不算检验杠杆**：分支相关的类率要写**差值**并写**功效**（P273 的教训）。
3. **settle 是下一段的起步信用**：删它，代价在下一段出现（P237/P254/P263）。
4. **`gap` 双峰**：吞吐必须报区间，不能报单点。
