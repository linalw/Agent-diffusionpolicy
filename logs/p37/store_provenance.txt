6. Recorded limitations
-----------------------
   * The rollout manifest has NO supply block (the collector's `supply.patch`
     field has no rollout twin), so the patch sheet is pinned by the command
     block above + logs/p37/collect_seed*.log, not by the manifest. Named
     follow-up: add a supply block to `rl_env._build_manifest` (it moves the
     `rl_env.py` md5 pin, so it is its own change).
   * `logs/` and `datasets/` are gitignored: committing this evidence needs
     `git add -f` (the P35/P36 convention).
   * A 2-episode instrumented smoke (`logs/p37/smoke.log`,
     datasets/rl_rollouts/p37_smoke, park diag ON, --record) ran before the
     collection to validate the path; it is NOT part of the store and was not
     merged.
