# P280 结果：遮挡体是**手**，不是臂——所以"换 Piper"打的是错的那一半

**2026-11-26。** owner 的猜想：松灵 Piper 比现在的臂更瘦，腕部相机遮挡应该更小。**猜想得到支持，
但它指向的是夹爪，不是臂**；而且现在的格子跑的就是**已经有小夹爪的 Panda**。

## 1. 先量：腕部视野里到底是谁挡着

`logs/p280/occlusion.py`：逐帧用腕部自己的深度，把**离相机比果子更近**的像素算出来——
在腕部 6 cm 的尺度上，"比果子更近"只可能是机器人。

| 时段 | 果子的掩码 | **挡在它前面的机器人** |
|---|---|---|
| 接近 | 6.15 % | **55.6 %** |
| 中段 | 2.91 % | **37.7 %** |
| 合拢 | 2.12 % | **25.3 %** |

（1198 帧，`logs/video_p279/wrist`）

**793/803 帧**里遮挡面积**超过果子本身的一半**；遮挡/果子面积比 p50 = **10.4×**。

**所以猜想的前半句成立**：机器人占掉腕部视野的 1/4–1/2，比果子大一个数量级。
**但"谁"是手**：相机在下颌后 6 cm 朝下看，挡在它和果子之间的只有**手指/掌**，
臂的连杆在相机**后面**。

## 2. 再试：把相机挪出视线（最便宜的那一档）

垫片外侧面在 ±59 mm，所以默认的 `FRUIT_WRIST_SIDE=0.045` 其实**还在手的投影里**。
测 `SIDE=0.09`（挪到外侧，10 连取，同配方）：

| 安装 | 接近 | 中段 | 合拢 | 果子掩码（合拢）| 放置 |
|---|---:|---:|---:|---:|---:|
| side 0.045（默认）| 55.6 % | 37.7 % | 25.3 % | 2.12 % | 5/10 |
| **side 0.09** | **33.5 %** | 42.5 % | **42.3 %** | 3.58 % | 4/10 |

**挪出去只治了接近段**（遮挡 55.6 → 33.5 %），**合拢段的遮挡反而升**（25.3 → 42.3 %），
果子掩码从 2.1 % 升到 3.6 %（可见性略好），**放置没有变**（4/10 对 5/10，一格分支）。
遮挡/果子比仍是 **10.9×**。

**这条说明**：只要相机在**下颌**上，无论往哪挪 4.5 cm，合拢时手都在视线上——
因为合拢时手**就在果子两侧**。

## 3. 对"换 Piper"的判决

| 项 | 判读 |
|---|---|
| 猜想的方向 | **对**：机器人确实占 1/4–1/2 的视野，比果子大 10 倍 |
| 该换的部件 | **不是臂，是夹爪**（遮挡全部由手指/掌贡献）|
| 现在的臂 | 已经是 **Panda**（76 mm 垫片、紧凑掌），不是大 OpenArm |
| Piper 能带来什么 | 掌更薄 → 占的像素少一些。**量级未知**，且**同一机理**：两指夹爪在合拢时必在果子两侧 |
| 代价 | **本地没有任何 Piper 资产**（repo 与 Isaac 库都没有）。加一个臂种是 `ArmSpec` 一条表项 + 标定位姿 + 工具偏移 + 触觉链（P227i→P227r 是**六个阶段**量出来的），而且 **P279 的分割器要按新手重新采集重训** |

## 4. 更可能有效的两档（都比重建一条臂便宜）

1. **把相机装到垫片外侧、朝内看**（finger-mounted）。现在 `_wrist_back/_side` 是**下颌相对**的偏移；
   改成**手指链接相对**（`_fingertip_offset` 与 `finger_links` 都有），视线就从"穿过手"变成
   "两个垫片之间的空隙"，这是**同一机理下**唯一能真正绕开手的位置。改动小，可用同一个
   遮挡普查 + 同一个分割器（需要少量新帧微调）来判。
2. **两面小镜 / 侧视棱镜**：把视线折 90°，相机本体留在掌后。硬件，但不动臂。

## 5. 复现

```bash
python3 logs/p280/occlusion.py logs/video_p279/wrist      # 默认安装的遮挡普查
FRUIT_WRIST_SIDE=0.09 <P279 配方> scripts/290_single_arm_continuous.sh 10 913 0.08
python3 logs/p280/occlusion.py logs/p280/wrist_side09
```

## 6. 不声称

* 不声称 `side 0.09` 更差：4/10 对 5/10 是一格分支（P93）。
* 不声称 Piper 不会更好：只说**遮挡全部来自手**，所以"更瘦的臂"只有在它同时带来**更瘦的掌/指**时才算数。
